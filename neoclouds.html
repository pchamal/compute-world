How this directory is kept honest

The question. Who rents GPUs / dedicated clusters? Do not put here: Token-only shops; full IaaS catalogs (those live with Hyperscalers).

No invented cities. If a provider is real but the city list is sales-gated, the record exists with undisclosed. lat/lon only when a named city exists (Wikipedia centroid). State-only rows are not upgraded to a metro.

No market caps. No fake fleet counts. Marketing GW figures appear only if they already sit in the JSON notes.

China and the EU appear even when the city is undisclosed. Classification is already in the JSON — Scaleway and OVH are regional hyperscalers; DigitalOcean / Vultr stay neoclouds because the product we care about is GPU Droplets / Cloud GPU.
